# All Goods Retail Store

This project is to create a sythetic dataset and pipeline for a retail store (single store) to answer questions, such as the following:

- How much profit are we generating?
- What is the best selling product/category?
- What is the most profitable category?
- What items are frequently sold together?
- What product is returned the most?
- How do promotions affect sales?
- How many customers are members?
- How many new members do we get each month?

This project will entail:
- Defining tables
- Writing data generation scripts 
- Relating tables
- Defining business rules
- Generating data
- Extracting the data
- Transforming/cleaning the data
- Loading the data into a postgres database
- performing analysis on the data
